  • Vie : l’agent répond à un challenge unique avant l’échéance.
  • Progrès : un digest, test, commit ou artifact vérifiable change.
  • Règle : heartbeat seul ≠ progrès; DuckDB projette les faits, l’event log reste autoritatif.
SIGNAUX DE SANTÉ COMPOSABLES
  • Présence ∈ {observée, absente, inconnue}
  • Preuve ∈ {fraîche, stale, invalide}
  • Flux ∈ {avance, bloqué, terminé}
  • Risque = raisons explicites, pas une moyenne opaque
  • Admission suivante = capacité prouvée − marge de sécurité
